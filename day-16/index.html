評価指標と混同行列

モデルの「良さ」を数字で測る物差しのセットです。混同行列の4つのマスから、すべての指標が計算できます。
ACCURACY / PRECISION / RECALL / F1 / AUC

# 混同行列# Precision / Recall# F1スコア# AUC-ROC
📏

一言で言うと

モデルの「良さ」を数字で測る物差しのセットで、混同行列の4つのマス（TP・TN・FP・FN）から全部の指標が計算できます。

今日の流れは「混同行列の4マスを理解する → 4つの指標を計算する → AUCでしきい値に依らない評価を見る」です。

01

混同行列って何？

「予測」と「正解」の組み合わせを並べた2×2の表です。各マスをタップすると、そのマスの意味が切り替わります。具体例として、100件の検査（本当に陽性10件・陰性90件）の結果を使います。

モデルの 予測 →

陽性と予測PREDICTED POSITIVE
陰性と予測PREDICTED NEGATIVE
正解は陽性
正解は陰性
正解が陽性：10件（TP 8 ＋ FN 2） 正解が陰性：90件（FP 5 ＋ TN 85） 合計：100件
02

4つの指標を計算する

指標はすべて、混同行列の4マスの組み合わせです。「どのマスを、どのマスで割るか」だけが違います。右端はセクション01の具体例（TP=8、FN=2、FP=5、TN=85）での計算結果です。

指標 計算式 何を測るか 具体例の結果
正解率ACCURACY (TP + TN) ÷ 全体 全体のうち、正しく予測できた割合 (8+85) ÷ 100 ＝ 93%
適合率PRECISION TP ÷ (TP + FP) 「陽性と予測したもの」のうち、本当に陽性だった割合。誤検知が増えると下がる 8 ÷ (8+5) ＝ 約61.5%
再現率RECALL TP ÷ (TP + FN) 「本当に陽性のもの」のうち、陽性と予測できた割合。見逃しが増えると下がる 8 ÷ (8+2) ＝ 80%
F1スコアF1 SCORE 2 × P × R ÷ (P + R) Precision と Recall の調和平均。片方だけ高いモデルはスコアが伸びない、バランスの指標 2×0.615×0.8 ÷ (0.615+0.8) ＝ 約69.5%

03

AUC-ROC

Accuracy などは「しきい値」を1つ決めたときの成績です。AUC-ROC は、しきい値を動かしたときの全体の傾向から、分類そのものの上手さを測ります。

ROC曲線：しきい値を動かしたときの軌跡

分類モデルは通常、「陽性らしさ」のスコアを出し、しきい値を超えたら陽性と判定します。しきい値を少しずつ変えるたびに、横軸の FPR = FP ÷ (FP + TN)（本当は陰性なのに陽性と予測した割合）と、縦軸の TPR = Recall を点で打つと、ROC曲線が描けます。

AUC はその曲線の下の面積です。1.0 が完璧な分類、0.5 はランダムと同じ（コイン投げと変わらない）ことを意味します。

強みは、しきい値を1つに固定せずに評価できること。「どのしきい値を選んでも全体として上手いか」＝分類そのものの上手さを測れます。

AUC の目安

0.5ランダムと同じ 0.75そこそこ判別できる 0.9優秀 1.0完璧な分類
04

試験で問われるポイント

混同行列の数値を与えて指標を計算させる問題と、不均衡データでの Accuracy の罠が定番です。

1

4マスから全指標が計算できる

混同行列の TP・TN・FP・FN さえ分かれば、Accuracy・Precision・Recall・F1 がすべて計算できます。数値を当てはめる計算問題は頻出です。

2

式の対応を正確に覚える

Accuracy = (TP+TN) ÷ 全体、Precision = TP ÷ (TP+FP)、Recall = TP ÷ (TP+FN)、F1 は Precision と Recall の調和平均。Precision の分母は「予測した陽性」、Recall の分母は「本当の陽性」です。

3

不均衡データでは Accuracy だけ見ると危険

99%が陰性のデータで「全部陰性」と予測しても Accuracy は 99% になります。役に立たないモデルが高スコアに見える ― これが Accuracy の罠です。

4

AUC-ROC は 1 に近いほど良い

AUC = 1.0 は完璧な分類、0.5 はランダムと同じ。しきい値に依存しない評価ができる点も合わせて覚えます。

05

間違えやすい点

Precision と Recall のトレードオフと、「目的によって見るべき指標が違う」ことがポイントです。

🎚️ しきい値を動かすと、Precision と Recall は逆向きに動く

しきい値を上げると「本当に確からしいものだけ」を陽性にするので誤検知が減り Precision は上がりますが、見逃しが増えて Recall は下がります。スライダーを動かして、トレードオフのイメージをつかんでください（数値はイメージです）。

低 高 0.50
適合率PRECISION
65%
再現率RECALL
66%

両方を同時に最大化はできません。だからこそ、目的に合わせて「どちらを重視するか」を決める必要があります。

Recall（再現率）重視

見逃しが一番まずい場面で選びます。病気の検査や不正検知では、陽性を見逃すコストが大きいため、多少の誤検知を受け入れてでも Recall を優先します。

VS

Precision（適合率）重視

誤検知が一番まずい場面で選びます。スパム判定では、正常なメールをスパムと誤判定すると大事な連絡を失うため、Precision を優先します。

🔑 見分け方：怖いのは見逃し（FN）か、誤検知（FP）か。FN が怖ければ Recall、FP が怖ければ Precision です。

分類の指標

今日学んだ Accuracy / Precision / Recall / F1 / AUC。「合っている・いない」を数えるタイプの指標です。

VS

回帰の指標

RMSE・MAE・R² は、数値を予測する回帰モデル用です。予測値と実測値の「ズレの大きさ」を測ります。

🔑 分類と回帰では物差しが別物です。モデルの種類に合った指標を選ぶこと自体が、試験でも実務でも問われます。
⚠️

Accuracy だけ見ると「何も予測しないモデル」が高スコアに見える

不均衡なデータでは、多数派に寄せただけのモデルでも Accuracy は高くなります。評価するときは必ず Precision・Recall・F1・AUC も併せて確認してください。
