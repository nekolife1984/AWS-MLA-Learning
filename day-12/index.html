Machine Learning — Lesson 12

SageMaker の組み込みアルゴリズムの選び方

SageMaker には、学習コードを書かずに使える組み込みアルゴリズムが多数用意されています。決め手は「何をしたいか」と「データの形」。今日は用途別にアルゴリズムを選び分けられるようになる回です。

# 組み込みアルゴリズム# XGBoost# K-Means# DeepAR
🧩

一言で言うと

組み込みアルゴリズムは「学習コードを書かず、アルゴリズム名・データ・ハイパーパラメータを指定するだけで学習できる」SageMaker の用意済みアルゴリズムです。選ぶ軸は「目的」と「データの形」の2つです。

01

選び方の3ステップ

ステップをタップすると、各ステップで何を判断するかが切り替わります。「目的 → データの形 → アルゴリズム」の順に進めば、候補は自然と絞り込めます。

› ›
02

図解：用途別マップ

起点は「データの形は？」という1つの質問です。表形式・画像・テキスト・時系列の4つの枝に、代表アルゴリズムを並べました。

アルゴリズム選びで最初に見るのは、アルゴリズムの名前ではなく手元のデータの形です。形が決まれば、使えるアルゴリズムは大きく絞られます。

データの形は？QUESTION — DATA SHAPE
▼ 表形式 ▼ 画像 ▼ テキスト ▼ 時系列
TABULAR

表形式データCSV など

行と列で表せる、最も一般的なデータです。分類・回帰の主戦場で、組み込みアルゴリズムの代表格がそろっています。

XGBOOSTXGBoost

分類・回帰に対応する表形式の代表格。勾配ブースティング（Gradient Boosting）で高精度が期待できます。

LINEAR LEARNERLinear Learner

分類・回帰に対応する線形モデル。高速でシンプルなため、ベースライン作りに向きます。

K-MEANSK-Means

クラスタリング専用の教師なしアルゴリズム。クラスタ数 k を事前に指定してグループ分けします。

IMAGE

画像データIMAGE

写真やイラストなどの画像が対象です。「何が写っているか」「どこにあるか」「どの領域か」でアルゴリズムが分かれます。

IMAGE CLASSIFICATION画像分類

画像全体をカテゴリに分類します。ResNet ベースのモデルが用意されています。

OBJECT DETECTION物体検出

画像内の物体の位置をバウンディングボックスで検出します。SSD ベースです。

SEMANTIC SEGMENTATIONセマンティックセグメンテーション

画像をピクセル単位で分類し、領域ごとに塗り分ける手法です。

TEXT

テキストデータTEXT

文章・レビュー・ドキュメントなどが対象です。分類に使うか、埋め込み表現に変換して使うかが分かれ目です。

BLAZINGTEXTBlazingText

テキスト分類と、単語をベクトル化する Word2Vec 埋め込みに対応する高速なアルゴリズムです。

OBJECT2VECObject2Vec

テキストなどを埋め込み表現（ベクトル）に変換し、分類・回帰などの下流タスクに使います。

TIME SERIES

時系列データTIME SERIES

時間とともに変化する値の並びが対象です。「将来を予測したい」のか「異常を見つけたい」のかで行き先が分かれます。

DEEPARDeepAR

時系列予測のアルゴリズム。RNN ベースで、関連する複数の時系列からまとめて学習できます。

RANDOM CUT FORESTRandom Cut Forest（RCF）

異常検知の教師なしアルゴリズム。時系列や数値ストリームの中の「いつもと違う値」を見つけます。

OTHERS

その他MORE ALGORITHMS

特定の用途に特化したアルゴリズムも用意されています。シナリオのキーワードと結びつけて覚えましょう。

FACTORIZATION MACHINESFactorization Machines

疎なデータに強く、推薦・分類・回帰に使えます。

IP INSIGHTSIP Insights

IP アドレスの分類に使う教師ありアルゴリズム。詐欺検知などに。

LDA / NEURAL TOPIC MODELLDA・Neural Topic Model

文書集合から話題を抽出するトピックモデリング（教師なし）。

PCAPCA

特徴量の情報を圧縮する次元削減（教師なし）。前処理にも使われます。

つまり、データの形から枝をたどり、目的で葉を選ぶだけです。表形式なら XGBoost、時系列の予測なら DeepAR、というように、組み合わせで候補が決まります。

04

試験で問われるポイント

MLA-C01 では、シナリオ文から適切な組み込みアルゴリズムを選ばせる問題が定番です。判断の型を3つ押さえましょう。

1

シナリオから用途を読み取る

問題文の「何をしたいか」が、そのままアルゴリズム選びのヒントです。表形式の分類なら XGBoost、ラベルなしのグループ分けなら K-Means、異常検知なら Random Cut Forest、時系列の将来予測なら DeepAR。シナリオのキーワードとアルゴリズムを結びつけて覚えましょう。

2

XGBoost と Linear Learner の違い

どちらも分類・回帰の両方に対応します。XGBoost は木ベースで非線形な関係も捉えられ高精度、Linear Learner は線形モデルで高速・シンプル・ベースライン向きです。非線形なパターンが強いデータなら XGBoost が有利になります。

3

組み込みアルゴリズムは学習コード不要

組み込みアルゴリズムは、アルゴリズム名・データ・ハイパーパラメータを指定するだけで学習できます。自分で学習コードを書くのは、Bring Your Own Container（BYOC）やスクリプトモードの場合です。試験では「コードを書かずに素早く試したい」というシナリオで、組み込みアルゴリズムが答えになります。

05

間違えやすい！混同しやすいポイント

名前や用途が似た組み合わせの取り違えが狙われます。「どちらも時系列に使えるけれど役割が違う」といった違いをここで潰しておきましょう。

XGBoost

決定木ベースの勾配ブースティング。非線形な関係も捉えられ、表形式データで高精度が期待できます。

VS

Linear Learner

線形モデル。高速でシンプル、結果も解釈しやすいのが強みです。

🔑 見分け方：どちらも分類・回帰対応です。データの関係が複雑なら XGBoost、シンプルで速さ重視なら Linear Learner を選びます。

DeepAR

時系列の将来の値を予測するモデルです。複数の関連する時系列から学習し、未来の需要や売上を出します。

VS

Random Cut Forest

時系列や数値ストリームで、今の値が異常かどうかを検知する教師なしアルゴリズムです。将来の値は予測しません。

🔑 見分け方：どちらも時系列データを扱いますが、聞かれているのが「将来の値」なら DeepAR、「異常」なら RCF です。

K-Means

教師なしのクラスタリング。正解ラベルなしで、データの類似性からグループを新しく作ります。

VS

分類

教師あり学習。ラベル付きデータで学び、新しいデータを既存のカテゴリに割り振ります。

🔑 見分け方：「グループを作る」のが K-Means、「既存のグループに入れる」のが分類。K-Means には正解ラベルが不要で、Accuracy での評価もできません。
